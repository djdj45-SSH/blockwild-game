# BLOCKWILD 3D — 去 AI 化 · 写实化 规格（v2）

## 一、为什么上一版「很 AI」

| 症状 | 成因 | 反制 |
| --- | --- | --- |
| 半透明毛玻璃卡片 | Glassmorphism 模板默认 | 实心哑光面板 + 1px 硬件边 + 斜切角 |
| 青绿→紫渐变标题 | AI mockup 配色 | 去渐变字；骨白/黄铜/血红 |
| 胶囊发光按钮 | SaaS landing | 方角/斜角机箱按钮，无 glow |
| 过度字距大写小标签 | 默认 HUD 套路 | 小号功能字，少大写、少 tracking |
| 三列等权卡片 hover 上浮 | 每个 AI 游戏 UI | 列表式密排 + 键位索引，非营销卡片 |
| 圆角 + 大留白 | 现代 Web 舒适区 | 军规密度：8–12px 边距节奏，信息优先 |
| 扫描线 + 玻璃混搭 | 风格断裂 | 全部去掉 CRT，换金属/帆布质感 |

## 二、新风格锚（写实射击 UI）

**锚**：Arma / Tarkov 菜单的**机箱密排** × Hunt: Showdown 的**低饱和气氛** × 现代战术 HUD 的**可读性**（不是科技感赛博）。

**不是**：玻璃拟态、赛博紫、霓虹描边、像素 CRT、SaaS 卡片。

### 字体

- 标题：`"Arial Narrow", "Oswald", "Segoe UI Semibold", sans-serif` 紧缩、重量 700
- 正文：`"Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`
- 数字：`"Consolas", "SF Mono", monospace` + `tabular-nums`
- 禁止：超大 letter-spacing 全大写装饰标签；渐变字

### 布局系统

- 8px 栅格；面板圆角 **2–4px** 或斜切 `clip-path`，绝不大圆角
- HUD **贴角实心条**，不居中漂浮
- 左：状态（HP/AP/等级）横向段条；右：弹药大数字 + 武器名；中上：紧凑罗盘/小地图
- 标题页：左文右角色/场景信息条，不是居中 hero + profile SaaS 卡
- 信息密度：小字 11–12px，数字 28–48px 仅用于弹药/分数

### 签名瞬间

1. **弹药读数**：黄铜描边方框 + 大等宽数字 + 小写 `/ 备弹`，像弹匣铭牌
2. **生命段条**：20 格断段，低血量整条转暗红并轻微闪烁（无彩虹渐变）
3. **标题**：紧缩大字「方块荒野」+ 一道细黄铜线 + 副标题小字；背后是**实时 3D 场景**不是色块
4. **准星**：精密十字 + 中心点 + 武器扩散弧（战术，非可爱）

## 三、写实画风（程序化，无外模）

| 系统 | 做法 |
| --- | --- |
| 材质 | Standard PBR；**Canvas 程序化纹理**（噪点、砌石、草地斑、木纹、金属拉丝） |
| 几何 | 人形 7.5 头身、锥形四肢、锁骨/骨盆块；枪械分段更细 |
| 光照 | 主光偏暖低角度 + 冷天空环境 + 接触阴影；shadow normalBias |
| 天空 | 多层噪声云 + 地平线雾 + 太阳散射 |
| 色调 | ACES/AgX 近似；轻微降饱和；阴影偏青、高光偏暖 |
| 后期 | 可选 Bloom（枪口）+ 轻晕影；不加噪点扫描线 |
| 地形 | 大尺度色变 + 细节贴图 + 路径磨损色 |

色彩目标：**更灰、更土、更尘**，去掉高饱和像素游戏感。

## 四、禁区

- 玻璃 blur 背板、渐变字、发光胶囊、紫青双色、hover 大位移
- 无意义的大写 tracking 标签
- 圆角 16px+ 的「卡片流」
- 扫描线 / 像素化 image-rendering

## 五、验收

- 截图对比：无玻璃感、无渐变字；黄铜/骨白/炭黑可识别
- 画面：草地有纹理斑驳、墙有砌石变化、阴影软、天空有云
- FPS ≥ 90 @1280×720（写实后允许下降，但需可玩）
- `node tools/verify.js` 仍通过（逻辑不动）
